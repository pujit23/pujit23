## What I'm building now

### [STRATA](https://github.com/pujit23/strata23) · Java 25
A from-scratch, single-node, filter-aware vector database: SIMD distance kernels (Vector API), off-heap memory (FFM), WAL + immutable segments, and a cost-based filter planner.
**Status:** early development. Kernels and tenant isolation work; the index, WAL, and planner are in progress. Progress is tracked in [`docs/implementation-status.md`](https://github.com/pujit23/strata23/blob/main/docs/implementation-status.md).
